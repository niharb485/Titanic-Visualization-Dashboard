# Titanic-Visualization-Dashboard 🚢

## 📌 Overview

This project presents a mini data visualization dashboard built using the Titanic dataset. The goal is to explore survival patterns through data cleaning, feature engineering, and multiple visualizations using Python libraries.

---

## 🎯 Objective

To analyze the Titanic dataset and communicate key insights visually through charts and concise interpretations.

---

## 🔍 Work Done

* Loaded and explored the Titanic dataset
* Cleaned missing values
* Removed irrelevant columns
* Created new features like:

  * Age Groups
  * Family Size
* Performed exploratory data analysis (EDA)
* Built multiple visualizations for storytelling

---

## 📊 Visualizations Included

* Survival Rate by Gender
* Survival Rate by Passenger Class
* Age Distribution Histogram
* Correlation Heatmap
* Survival by Family Size
* Facet Grid Comparison (Optional)

---

## 💡 Key Insights

* Female passengers had significantly higher survival rates
* First-class passengers were more likely to survive
* Most passengers were young adults
* Family size influenced survival probability
* Fare and passenger class showed strong correlation with survival
